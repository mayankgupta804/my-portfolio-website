# mayankgupta.space — Futuristic Portfolio SPA

Personal portfolio website for **Mayank Gupta** (Senior Software Engineer — Go, Elixir, Distributed Systems, Microservices on Linux).

## Features
- **4 Live Interactive Design Modes** (switchable in real-time via the bottom Design Lab Dock or `Cmd+K`):
  1. **01 // Orbital Telemetry HUD** — Deep-space command center with cyan/amber telemetry and live node topology.
  2. **02 // Industrial DSP & Hardware Deck** — Inspired by Neural DSP & Teenage Engineering hardware racks.
  3. **03 // Spatial Glass & Aurora Bento** — Cosmic frosted glass bento grid with aurora lighting.
  4. **04 // CAD Schematic Blueprint** — Neo-brutalist engineering blueprint with 1px grid crosshairs.
- **Interactive Visualizers**:
  - **Distributed Systems Topology**: Clickable Go/Elixir/Kafka microservice nodes with peak-traffic stress-test simulation.
  - **The Tone Chaser DSP Rack**: Interactive Drop-G baritone guitar spectrum analyzer (`G0–A2`), WebAudio string synthesizer, and 5-stage pedal/amp signal chain (*Peer Pressure Inc.*).
  - **Endurance & Elevation HUD**: Interactive Bangalore Ultra to Uttarakhand (3,680m) elevation contour chart & DIY mechanical specs.
- **Command Palette (`Cmd+K` / `Ctrl+K`)**: Instant keyboard navigation across sections, themes, and external links.

## Local Development

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) to preview and test all 4 designs.
